
# fifo_async 

# 仕様

## 以下のパラメータ設定可能
1. データビット幅
2. FIFOサイズ
3. 同期化回路のFF段数
4. almost full スレッショルド
5. almost empty スレッショルド


## fifo ステータス
各ドメインごとに、以下のステータスを確認可能

1. empty
2. full
3. almost empty
4. almost full
5. 現在のfifoに入っているデータ数(fifo available)

## その他

fullの時、書き込みしても無視
emptyの時、読み込みしても、有効なデータは帰ってこない(validが立たない)
